미리보기는 운영 로그인 없이 가상 운영진으로 열리며, 운영 인증을 대체하지 않습니다. 외부 요청은 CSP와 전송 차단 코드로 막습니다. 미리보기의 변경 내용은 운영 DB에 저장되지 않습니다.

남은 확인 사항과 다음 개선

1. 실제 iPhone Safari와 카카오톡 브라우저에서 인증 유지, UID 복사, 파일 저장, 회전과 키보드 표시를 확인해야 합니다. Chromium의 화면 크기 시뮬레이션으로 이를 보증하지 않습니다.

2. Supabase 스키마와 RLS 및 서버 RPC의 실제 권한 검증은 자료가 없어 확인하지 못했습니다. 프런트엔드 탭 숨김만으로 보안을 증명하지 않습니다.

3. Apps Script의 no-cors 응답은 저장 성공을 확인할 수 없습니다. 확실한 접수 번호와 서버 확인 화면을 제공하려면 Apps Script의 응답 계약을 별도로 점검해야 합니다. 이번 수정은 기존 요청 형식을 유지합니다.

4. 엑셀 라이브러리의 실제 다운로드 및 Excel에서 파일 열기는 미검증입니다. 기존 가져오기와 내보내기 코드를 제거하지 않았습니다.

5. 제출 현황의 기본 조회는 최신 1,000건, 검색어 없는 변경 이력은 최신 120건이라는 기존 정책을 유지합니다. 이것은 전체 원본 데이터 삭제나 초기화가 아닙니다.

6. 기존 JSON 백업은 서버, 연맹, 인원, 전투력 기록, 제출 테이블 범위입니다. 투표 및 전략맵 전체를 복구하는 통합 백업은 아닙니다. 수도전은 별도 JSON 백업을 유지합니다.

7. 기존 admin.html에는 통합시트와 별도인 예전 관리 흐름이 남아 있습니다. 파일을 삭제하거나 새로운 관리자 페이지로 대체하지 않았습니다. 실제 사용 여부와 Apps Script의 서버 권한 검증은 운영 검토 항목입니다.

운영 반영은 사용자 확인 전까지 진행하지 않습니다. 공개되는 변경은 가상 데이터 미리보기 브랜치뿐입니다.
